# 学堂在线全能助手（xuetangx-helper）

一个用于 [学堂在线](https://www.xuetangx.com/) 的油猴（Tampermonkey）脚本，把「看视频、刷题、整理题库」这些重复劳动交给脚本。

> ⚠️ **使用前请阅读**
> 本脚本仅供**个人学习与前端技术交流**使用。请自行确认它是否符合学堂在线用户协议以及你所修课程的学术规范；
> 因使用本脚本产生的一切后果（课程进度、成绩、账号状态等）由使用者自行承担。
> 请不要在任何正式考试、计分考核中使用自动作答功能。

---

## 功能

### 自动刷课
- 视频自动播放、自动静音；**切集/切清晰度后有声音会自动重新静音**；
- 按面板选择的倍速播放（1.0x / 1.25x / 1.5x / 2x）；
- 播放到尾段后按左侧目录顺序自动进入下一单元（先"尾段两次确认"再翻页，避免误跳）；
- 左侧目录筛选成「视频」后，点一次「自动刷课」就能一路刷下去（不要求勾选「允许自动翻页」）。

### 自动作答
- **题库模式**：从本地题库按题干匹配答案；
- **大模型模式**：接入任意 OpenAI 兼容接口（默认官方 DeepSeek + `deepseek-flash`），按题型（单选 / 多选 / 判断 / 填空 / 简答 / 名词解释 / 论述 / 计算）定制提示词与解析规则；
- 题干或选项里含图片时，可交给多模态模型识别（失败会自动降级为纯文字）；
- 答案落到页面后自动点「提交」，并回读校验是否真的交上去，没生效才重试。

### 选中选项后自动提交
选中选项后脚本自动点「提交」并确认；同一份选择只自动交一次，**改答案会重新提交**；答题任务运行期间由任务自己提交，两者互不打架。

### 参考资料库
可一次导入多份 **PDF / PPTX / DOCX / TXT / MD / JSON**，脚本按题干做 bigram + IDF 检索，只把最相关的几段注入提示词 —— 不把整份讲义发给模型，省 token 也更准。

### 题目提取与题库管理
整卷 / 单页提取，按题型与题号排序，支持复制或导出 JSON 题库。

## 安装

1. 安装浏览器扩展 **Tampermonkey（篡改猴）**：<https://www.tampermonkey.net/>
2. 安装脚本，任选一种方式：

   | 方式 | 链接 | 说明 |
   |---|---|---|
   | jsDelivr CDN | <https://cdn.jsdelivr.net/gh/Yakap168/HFUT-Yakap168@main/xuetangx-helper.user.js> | **国内推荐**，无需代理 |
   | GitHub Raw | <https://raw.githubusercontent.com/Yakap168/HFUT-Yakap168/main/xuetangx-helper.user.js> | 部分网络环境需要代理 |
   | Releases | [最新版本](https://github.com/Yakap168/HFUT-Yakap168/releases/latest) | 下载 `.user.js` 后拖进浏览器即可 |

3. 在 Tampermonkey 面板确认脚本为**已启用**，然后刷新学堂在线页面（`https://www.xuetangx.com/`）。

> 脚本内置了 `@updateURL`（指向上面的 jsDelivr 地址），只要用这两个链接之一安装过一次，之后有新版本 Tampermonkey 会自动提示更新。

## 使用

打开任意课程页，右下角会出现悬浮面板（可拖动，双击标题栏复位）：

| 区域 | 说明 |
|---|---|
| 自动刷课 | 开始 / 停止刷课 |
| 播放倍速 | 1.0x ~ 2.0x |
| 允许自动翻页 | 仅当检测到"当前单元已完成"时才翻到下一单元 |
| 选中选项后自动提交 | 默认开启，可随时关闭 |
| 答题模式 | 题库作答 / 大模型(AI)作答 |
| AI 配置 | API 地址、模型名、密钥；**保存后请点「测试连接」自检** |
| 参考资料 | 导入 PDF/PPTX/DOCX/TXT/MD/JSON，可多选；可开关"识别题目图片(视觉)" |
| 提取当前页 / 自动翻页提取 | 只抓题，不提交答案 |
| 自动答题并提取 | 每题先随便选一个并真实提交，再从页面读回正确答案存题库（**会消耗提交次数**） |
| AI作答（大模型）/ 按题库作答 | 按当前模式自动作答、提交并翻到下一题 |
| 返回第一题 / 清空本地题库 | — |

**AI 配置要点**：模型名必须填接口实际支持的名称（官方 DeepSeek 支持 `deepseek-flash`、`deepseek-v4-pro`），填错会直接返回 HTTP 400。密钥以明文保存在本机脚本存储中，题目文本会发送到你填写的 API 地址，请自行确认可信度。

## 常见问题

**Q：选了选项但没有自动提交？**
确认面板勾选了「选中选项后自动提交」，并且没有答题任务在运行（任务期间由任务自己提交，旁观逻辑不介入）。另外页面需要处于前台标签 —— 浏览器会把后台标签的定时器限流，脚本已针对"用户点击"做了事件驱动补巡检，但极端情况下后台停留仍可能延迟。

**Q：导入资料时在文件夹里找不到我的 PPTX？**
本脚本已去掉文件类型过滤，任何文件都能选进来；格式在解析阶段判断，不支持的格式会给明确原因（例如旧版 `.ppt/.doc` 二进制格式请另存为 PPTX / DOCX）。

**Q：静音后过一会儿又有声音？**
播放器在切集/切清晰度时会把音量状态回写。脚本会在检测到仍未静音时重新静音（同时把 `volume` 置 0），并在每轮巡检复查。

**Q：AI 作答只答了一题就停了？**
已在 v4.3.10 修复：页内「下一题」按钮与「提交」同源，早期版本只给提交开了通道。请确认脚本版本为 v4.3.10 以上。

**Q：遇到 bug 怎么办？**
欢迎[提 Issue](https://github.com/Yakap168/HFUT-Yakap168/issues)，请附上：脚本版本、浏览器与 Tampermonkey 版本、复现步骤，以及 F12 控制台里的 `[助手]` 日志。
